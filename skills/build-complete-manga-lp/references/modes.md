# 商品・目的・販売ストーリー

## 商品タイプ

| ID | 対象 | 主な証拠 |
|---|---|---|
| `story_ip` | 小説・漫画・物語作品 | 一場面、感情体験、次の謎 |
| `knowledge` | 本・教材・講座 | 中身、手順、ワーク、小さな理解 |
| `service` | 伴走・サブスク | 利用過程、支援、複数日の変化 |
| `tool` | アプリ・業務ツール | 画面、操作、出力 |
| `physical` | 道具・機器・物販 | 実物、使用、比較、細部 |

## LP目的

- `awareness`: 認知・共感。余韻を残す。販売圧は弱め。
- `trial`: 試し読み・無料導線・比較。小さな成功を1回見せる。
- `conversion`: 購入・申込。証拠ループを2回以上見せ、具体的CTAで閉じる。

## 選べる9ストーリー

| ID | 向くケース | 核 |
|---|---|---|
| `recommendation` | 人や媒体の推薦 | なぜ勧めるか |
| `testimonial` | 読者に近い体験者 | Before→使用→After |
| `developer` | ツール・独自機能 | 問題→実演→証拠 |
| `story_intro` | 作品紹介 | 世界、人物、次の謎 |
| `story_experience` | 物語を疑似体験させる | 危機、仕組み、引き |
| `insight` | 本・教材・啓発 | 常識の反転と気づき |
| `documentary` | サービス・伴走 | 利用日程と変化 |
| `desire` | 欲しい未来が明確 | 願望→障壁→実現 |
| `achievement_journey` | 利用者と決裁者が別 | 困りごと→仲間→相談→体験→成功→明るい未来 |

通常は `auto` を使い、推奨を含む最大3案をユーザーへ提示する。狙う広告表現をユーザーが指定した場合だけ手動選択する。商品種別を問わず、利用者と決裁者が別の商品を購入へ導く場合、`auto` は成長実感型を優先する。
