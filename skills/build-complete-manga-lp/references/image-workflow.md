# Gemini Sparkでの画像制作

## 作画順

1. `python3 scripts/builder.py prompts <job>` で `reports/image_jobs.json` を作る。
2. キャラクター参照シートを先に作る。最低3枚。基本・表情・動作の3枚、または主要3人物の各1枚とする。
3. 各パネルを番号順に作る。ジョブの `references` をすべて画像生成ツールへ渡す。
4. 画像内へ文字・吹き出し・ロゴを描かせない。第三者の企業・商品・サービスを想起させる名称、キャラクター、画面、制服、特徴的な意匠も描かせない。文字は後工程で正確に合成する。
5. 生成結果をジョブの `target` へPNGで保存する。別の場所へ出た場合は対象パスへコピーする。
6. `python3 scripts/builder.py status <job>` で不足0を確認する。

新規画像はGemini Sparkで利用可能な画像生成機能を使う。Mac版では、案件フォルダをConnected folderとして明示的に許可してから保存する。編集対象のローカル画像がある場合は先に目視し、すべての参照画像を渡す。キャラクターの顔、髪、服、体型、主要小道具をページ間で固定する。

画像生成またはPNG保存が利用できない場合は、`reports/image_jobs.md` を渡して停止する。その状態は「プロンプト完成」であり「漫画LP完成」ではない。Mac版Sparkへ移り、案件フォルダをConnected folderに追加すれば再開できる。プレースホルダーの `preview` を完成品として渡さない。

作画後は全ページを目視し、次を確認する。

- 同じ人物に見えるか
- 指、顔、小道具、商品形状に破綻がないか
- 吹き出し予定位置に顔や重要物がないか
- 第三者の企業名・商品名・サービス名・ロゴ・キャラクター・特徴的な意匠、透かし、不要な文字がないか
- 未成年を含む場合に不適切な身体強調や危険表現がないか
